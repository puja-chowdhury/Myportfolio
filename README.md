# Puja Chowdhury — Portfolio

Static HTML, CSS and JavaScript portfolio. No installation or build step required.

## Publish on GitHub Pages
1. Create a repository named `puja-portfolio` on GitHub. Use a public repository for a straightforward GitHub Free setup.
2. Extract this ZIP. Upload its CONTENTS to the repository root, including `index.html`, the `work-screenshots` folder and the resume. Do not upload only the ZIP or wrap the files in another folder.
3. Commit the files to `main`.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/(root)`, then Save.
7. Wait for deployment, then use the Visit site link on the Pages settings screen.

The standard address is https://YOUR-USERNAME.github.io/puja-portfolio/ (replace YOUR-USERNAME).
The GitHub Pages site is public; this export does not carry over the private access of the original hosted portfolio.

## Edit
- `index.html` contains all page content, CSS and JavaScript.
- `work-screenshots/` contains selected work excerpts only.
- `Puja_Chowdhury2026.docx` powers the resume download.
- Keep relative file paths and filename capitalization unchanged.
- Open index.html in a browser to preview locally.
- Future edits to the original hosted site do not automatically update this export.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
